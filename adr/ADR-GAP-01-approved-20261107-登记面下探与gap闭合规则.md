## 1. 问题

8 个 open gap 中有 5 个是同一形状：`G-CRD-1`（5.2.2 两行）、`G-DEC-1`（2.2.1 五行）、`G-CTR-1`（3.2.1／3.2.2 六行）、`G-STP-1`（4.2.2 两行）、`G-DFL-1`（4.2.4 三行）——均因「缺行级书目登记面」而 open。现行口径下，关闭几乎只有「补到行级」一条路；但有些行客观上不存在更细粒度的外部出处，导致 gap 永久悬挂，SO-7～SO-11 永久 open。

本 ADR 要裁决：**当书目没有更细粒度登记面、或该行义务本就由母本自持时，能否以及如何合法关闭这类 gap。**

### 2.2 现行口径的约束

- **0.12 + 0.17.7 门槛 6 + 0.17.8 M6**：文献必须载明所支撑主张；`narrative_only` 不具备决策级佐证力。
- **`ADR-STY-FIM-01` §5.5(2)**：`external` ＝行级外部书目且登记面覆盖本行；`mother-row`＝母本表格行本身；`mother-definition`＝母本自建定义行且过 FIM-1 F1–F5；`fallback`＝整条记录无表格无文献的人工判断。
- **§5.5(3) 判错处置**：把表级／节级下探记成 `external`，按 0.12 驳回。
- **`ADR-G-OWN-CSL-01` 先例**：4.2.1／4.2.3 五行本在表内，缺的是**行内出处文本**；经人类批准在母本行内补「行级出处：书目 N」，零插行。该 ADR 同时写明「书目 35 的表级面不得下探纪律保留于表级」。

### 2.3 一处既有不一致（必须由本 ADR 一并裁明）

## 3. 三种闭合状态

> 三态仅覆盖「缺行级书目登记面」这一类 gap。其它闭合形状（结构补标记、文档指向、运行期事实、封闭词汇、Waiver、schema 修订）不在本规则射程，见 §6。

### 3.1 状态 ①：补到行级

| 项 | 内容 |
|---|---|
| 定义 | 找到或补入**行级**外部出处，登记面明确覆盖该行；`source_class: external`；gap 关闭 |
| 两种合法形态 | ①a：`references` 直接记 `bib_id`＋`support_claim`；①b：按 `ADR-G-OWN-CSL-01` 先例，在母本行内补「行级出处：书目 N」（零插行） |
| 证据 | 书目原文/登记句逐字；`compile_usage` 须为可决策级（非 `narrative_only`）；`support_claim` 与行内义务逐项对应；行锚可反查 |
| 谁认定 | 提议：Agent；批准：人类责任方（0.13） |
| 留痕 | `closure.basis` 写「书目 N 行级覆盖」；`evidence` 列 ADR／母本行号／台账 diff；`references` 落 `bib_id` |
| 对 SO | 对应 SO 随 gap 同批关闭（证据即书目本身） |

### 3.2 状态 ②：裁定以表级／节级登记面为准

| 项 | 内容 |
|---|---|
| 定义 | 书目**自身没有更细粒度**，其表级／节级登记面被人类裁定为该行的权威出处面；`source_class` **仍记 `mother-row`**（不记 `external`）；gap 关闭 |
| 与 `external` 的界线 | ②**不**把表级面写成行级出处，只登记「行级下探不成立」；若写成 `external` 即违反 §5.5(3)，本状态不成立 |
| 必备证据 | ①书目登记句逐字（表级／节级）；②**书目自述的粒度边界**（如「仅覆盖 schema registry」「本章只到模式级」）；③检索记录（§5）；④人类裁定句 |
| 谁认定 | 提议：Agent；裁定：人类责任方；不得由 Agent 自批 |
| 留痕 | `closure.basis` 明写「行级下探不成立的理由＝书目本身无更细粒度，非未查」；`evidence` 含书目粒度自述与检索记录 |
| 对 SO | 对应 SO 关闭，`closure` 互链；义务从「补书目」转为「已勘察并裁定无更细面」 |

### 3.3 状态 ③：在所登记书目范围内无行级出处、义务由母本自持

| 项 | 内容 |
|---|---|
| 定义 | 检索后确认**在所登记书目范围内**无书目登记该行，且该行义务可由母本自足；`source_class` 按实体类别记 `mother-definition`（须过 FIM-1）或 `mother-row`／`mother-clause`（定义不成立时）；gap 关闭 |
| ③a／③b | ③a＝在所登记书目范围内完全无行级出处；③b＝**部分外部覆盖**（书目只覆盖该行一部分且自述边界），未覆盖部分由母本自持，`references` 保留为部分支撑、不升格为 `external` |
| 必备证据 | ①检索记录（§5，含范围与结论）；②母本自足性证明：义务句/判定规则逐字＋行锚；③若记 `mother-definition`，另须 FIM-1 F1–F5 逐项证据并经单独 ADR（`ADR-STY-FIM-01` §6 的 CRD-007 边界同样适用） |
| 谁认定 | 提议：Agent；裁定：人类责任方；`mother-definition` 须另立 ADR |
| 留痕 | `closure.basis` 写「所登记书目范围内无行级出处＋母本自持」；`evidence` 含检索记录、母本定义句、FIM-1 表（如适用） |
| 与 `fallback` 的界线 | ③的载体是**母本表格行或条款**，故**永不记 `fallback`**；`fallback` 仅用于「整条记录无表格无文献」的人工判断（§5.5(2)），且须逐条 MJ 登记 |

> **措辞限定（D2，2026-11-07 批准时收紧）**：③的结论一律表述为「**在所登记书目范围内无行级出处**」，不得写成「无外部出处」。该结论是**对本项目所登记书目的断言**，不构成对该主题是否存在外部文献的断言；未登记文献不作为本状态的检索对象（补登记属 0.12 扩充，另案）。②的结论同理，仅断言「书目自身无更细粒度」。

### 3.4 三态对照

| 维度 | ① 补到行级 | ② 表级／节级为准 | ③ 母本自持 |
|---|---|---|---|
| `source_class` | `external` | `mother-row` | `mother-definition`／`mother-row`／`mother-clause` |
| `references` | 记 `bib_id` | 可留书目为「面级参照」，不作行级出处 | ③a 空；③b 保留部分支撑 |
| 行级下探 | 成立 | **不成立**（写入理由） | 不适用（无外部面） |
| 需要检索记录 | 否（有原文即可） | **是** | **是** |
| 需要 FIM-1 | 否 | 否 | 仅 `mother-definition` |
| 人类裁定 | 批准登记 | 必须 | 必须 |
| 对 SO | 同批关闭 | 同批关闭 | 同批关闭 |

## 4. 与既有口径的衔接

1. **0.12 行级口径不变**：②不扩张 0.12，只是承认「该书目到表级为止」；行级出处仍只有 ①。
2. **`source_class` 五值不扩**：三态复用既有五值，不新增枚举；②固定 `mother-row`，③按实体类别。
3. **与 `fallback` 不打架**：③的载体必为母本表格行或条款；`fallback` 仍专指「整条无表格无文献」。二者互斥，且 `fallback` 须 MJ 登记。
4. **与 `mother-definition` 的边界**：③不等于自动获得 FIM-1；`mother-definition` 须 F1–F5 全过并另立 ADR（CRD-007 的暂缓结论优先）。

## 5. 防滥用（硬性）

1. **「未查」不得记 ②／③**：没有检索记录的「无更细粒度」「在所登记书目范围内无行级出处」一律视为未勘察，gap 与 SO 均保持 open。
2. **检索记录五要素**（缺一不得闭合）：检索范围（书目编号/版本/章节）、检索词与路径、执行人、执行日期、结论（含反例：哪些候选被排除及理由）。**范围须写明「已登记书目」；结论须用 D2 限定措辞。**
3. **②须有书目粒度自述**：仅有「我查了没找到」不够，须引书目自身的边界句（如 bib33「不覆盖网关／服务目录」）。
4. **③须有母本自足句**：须逐字给出义务句与行锚；不得以「母本没写但常识如此」补足（F5 不可复现即不成立）。
5. **禁止把 ②／③ 当捷径**：若存在尚未登记但可登记的行级书目，必须走 ①；②／③ 只处理「客观上没有更细面」或「义务母本自持」。
6. **禁止 Agent 自批**：状态 ②／③ 的裁定与 `status` 改写只能由人类责任方执行（0.10／0.13）。
7. **可重开**：出现新的行级书目证据时，按 0.22 保留旧记录并新开 ADR 重判；不得静默改写既有 `closure`。
8. **结论外延限定（D2）**：②／③ 的结论只断言「本项目所登记书目范围内」的事实，**不构成对该主题是否存在外部文献的断言**；引用该结论时不得省略「在所登记书目范围内」这一限定语。

**不自动关闭原则**：若一个 SO 的 scope 跨多个 gap（如 `SO-3` 同时承接 `G-STY-3` 与已关闭的 `G-STY-5`），单个 gap 关闭不自动关闭 SO；SO 关闭须其 scope 内全部 gap 关闭或 route 由人类改指。SO-7～11 各自单指一个 gap，可一比一关闭。

## 8. 与 `ADR-G-PRJ-1-01` 的关系

`G-PRJ-1` 缺的是**交付空间的可判定事实**（谁组织评审、谁签字等），不是书目出处；任何书目都无法提供，因此三态不适用，也不得用 ②／③ 关闭。它按 `ADR-G-PRJ-1-01` 保持 `open`、无 SO 承接，作为负例留存。**判据：缺「文献怎么说」→ 三态；缺「本项目事实是什么」→ 运行期事实缺口。**
